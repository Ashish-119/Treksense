How to test the "intermittent connectivity" part of the DoD

  1. Step through a few waypoints normally (online) — watch tiles accumulate and old ones evict once you're > 250 km from the prepared centre.
  2. Open DevTools → Network → set Offline.
  3. Click "Next waypoint →" once or twice — should log "skipped: offline" with a backoff time, and the store must stay exactly as it was (nothing evicted, nothing corrupted — same guarantee Stage 2 verified).
  4. Set Network back to Online, keep stepping — the very next waypoint past the backoff window should prepare normally again.
DoDstore always covers ~100 km around the mock position wherever a connection was available; storage stays bounded
